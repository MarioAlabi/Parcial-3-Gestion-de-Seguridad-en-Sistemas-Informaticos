Puesta en Marcha del Simulador (Flask)

El simulador Security Workbench corre en un servidor local ligero de Python/Flask. Para iniciarlo en tu máquina, sigue cualquiera de estos dos métodos:

Método 1: Script Automático (Recomendado)
cd Laboratorio_XSS
./iniciar_laboratorio.sh
Método 2: Manual con Python
cd Laboratorio_XSS
pip install -r requirements.txt
python3 app.py
Método 3: Con Docker Compose
cd Laboratorio_XSS
docker compose up -d
Una vez iniciado o desplegado, accede en tu navegador a la ruta: /simulador
